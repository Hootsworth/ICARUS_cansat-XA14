[ROUND 02 / PRE-FLIGHT READINESS REVIEW]

CanSat Subsystem Inspection Stations

Inspect 5 engineering stations. Analyze strip charts, telemetry logs, and flight criteria. Determine whether each subsystem is GO or NO-GO for launch. Up to 500 PTS (+100 PTS per correct station).

[STATION 01 / ELECTRICAL POWER SYSTEM]

EPS Battery Voltage Sag Under Transmit Pulse

[CRITERIA]: V_bat must remain ≥ 3.30V during 500mA radio transmit burst. If V < 3.30V, MCU brownout risk.
[DATA]: Idle V: 3.74V. During 100ms LoRa TX packet: V dips to 3.18V for 85ms before recovering to 3.65V.
[STATION 02 / RECOVERY SUBSYSTEM]

Parachute Ejection Door Servo Interlock

[CRITERIA]: Servo travel 90° ± 5°; stall current < 250mA; physical door limit switch confirmed.
[DATA]: Measured angle: 89.2°. Current spike: 180mA for 120ms then drops to 45mA idle. Limit switch telemetry returns DOOR_UNLATCHED=1.
[STATION 03 / NAVIGATION & GNSS]

GNSS 3D Fix & Horizontal Dilution of Precision (HDOP)

[CRITERIA]: 3D fix with ≥ 6 satellites tracked; HDOP must be ≤ 2.0 for precise landing telemetry.
[DATA]: Satellites in view: 8. Fix type: 3D-FIX. HDOP = 4.2 (Multipath reflection from launch crane observed).
[STATION 04 / SENSOR CALIBRATION]

Barometric Altimeter vs Airfield QNH Datum

[CRITERIA]: Pre-launch elevation reading within ±10m of airfield surveyed benchmark (860m MSL).
[DATA]: Local METAR QNH: 1013.25 hPa. Sensor reads 864m MSL (Δ = +4m). Residual variance < 0.4m over 60s sample.
[STATION 05 / TELECOMMUNICATIONS]

LoRa 433MHz Ground Station RF Link Margin

[CRITERIA]: Received RSSI ≥ -115 dBm; SNR ≥ -5 dB at 1.5 km range. Minimum link margin > 10 dB.
[DATA]: Measured RSSI = -98 dBm, SNR = +7.5 dB. Noise floor = -120 dBm. Calculated link margin = +14.5 dB.
